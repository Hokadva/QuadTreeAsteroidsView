# QuadTree Asteroids

A project simulating the motion of random asteroids and their perfectly elastic collisions using a quadtree for efficient collision detection.

## Run

```bash
git clone https://github.com/Hokadva/QuadTreeAsteroidsView.git
cd QuadTreeAsteroidsView

pip install -r requirements.txt
python main.py
```

Requires Python 3.10+
